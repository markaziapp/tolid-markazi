# بازار صنعتی استان مرکزی

پلتفرم رایگان B2B برای اتصال تولیدکنندگان و مشتریان صنعتی استان مرکزی.

## ساختار پروژه
- `worker/` — کد بک‌اند (Cloudflare Worker + D1 + R2)
- `public/` — فرانت‌اند سایت عمومی، پنل کارخانه، و پنل مدیریت مخفی
- `schema/` — اسکیمای پایگاه‌داده
- `docs/README.md` — **راهنمای کامل و ساده راه‌اندازی؛ از همین‌جا شروع کنید**

برای راه‌اندازی، فایل `docs/README.md` را باز کنید و مرحله‌به‌مرحله دنبال کنید.
